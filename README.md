# Text-Based Adventure Game in Python

Step into the shadows. Read, choose, survive.

## A text-based adventure game for the terminal, written in pure Python. No dependencies, no setup. Just run it and start reading.

bash
python prolog_ausgabe.py
Multiple Choice

## At key moments you decide what happens next. Pick one of the options, and your decisions shape how the story ends.

Do you want to turn the body over?   -> go to 51
Do you want to hide in a corner?     -> go to 41
Do you want to leave the room now?   -> go to 72
Progress
